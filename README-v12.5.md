# v12.5 — Institutional Analysis Completion

Scope is limited to completing and strengthening the existing CAT/Exam reporting path.

- CAT DOCX follows the supplied institutional sequence:
  cover, general comments, purpose, Table 1 participation by group,
  Table 2 trainer/unit/cohort performance, Table 3 missed CATs,
  conclusion, recommendations, prepared-by line.
- Exam DOCX follows the supplied institutional sequence:
  cover, general comments, purpose, summary, group participation,
  result analysis per trainer/unit/group, missed exams per unit,
  missed-all-exams table, failed/supplementary table,
  conclusion, recommendations and approval lines.
- CAT performance threshold remains 8/15.
- Exam grade bands: A >=75, B 65-74.9, C 50-64.9, D 40-49.9, E <40.
- Official report download buttons are only enabled when the underlying markbook data is ready.
- No database migration and no new assessment feature is introduced.
