# v12.6d — Student-Row Borders & Cohort Mean Summary

Workbook refinements:
- borders are removed from the institutional/meta rows
- borders are removed from the marks column heading row
- borders remain only on actual student data rows
- each cohort worksheet gets a compact COHORT MEAN SCORE and MEAN GRADE summary
- exam mean score uses only fully completed records: Assignment + Presentation/Practical + RAT + CAT 1 + End-Term Exam must all be numeric
- absent (AB), incomplete, and partially filled rows are excluded from the exam mean
- mean grade uses the agreed scale:
  A 75–100 Distinction
  B 65–74 Credit
  C 50–64 Satisfactory
  D 40–49 Pass
  E below 40 Fail

No database migration.
