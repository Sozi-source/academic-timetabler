Academic Timetabler v10.3 — Fixed departments, shared trainers and personal DOCX
================================================================================

Prerequisite
------------
Install v9.5 first. This is a cumulative patch and includes all fixes from
v9.6 through v10.2. Do not apply the older v10.2 ZIP separately when using
this patch.

What this changes
-----------------
- Removes the department switcher. Each HOD/admin login remains anchored to
  its primary department and prepares that department timetable.
- Keeps trainers in one institution-wide pool while preserving each trainer's
  home department and home-department ownership of the trainer record.
- Shows every active trainer in the allocation picker, including home
  department and total institutional workload.
- Shows only trainers allocated by the current department in its allocation
  workload cards, while their displayed hours include every department.
- Blocks institution-wide trainer double-booking at the database boundary,
  including simultaneous changes made by two departments.
- Calculates trainer workload across all departments and enforces the
  institution-wide maximum. Normal target hours remain a soft target, so
  extra hours are still allowed and clearly reported.
- Keeps automatic smart exchanges within the current department, as required.
- Makes personal trainer and trainer-workload reports institution-wide so a
  shared trainer receives one complete schedule.
- Adds an editable Word export for personal trainer timetables. Each assigned
  trainer gets a separate portrait page with period, scheduled hours, target,
  teaching departments, unit, cohort and venue.
- Keeps the v10.2 editable department master Word export and all previous
  direct-publication, live-draft editing and same-name shared-class fixes.

Apply from PowerShell
---------------------
1. Stop the development server with Ctrl+C.
2. Run these commands from the academic-timetabler project root:

   $zip = Get-ChildItem "$env:USERPROFILE\Downloads\timetabler-patch-v10.3-fixed-department-shared-trainers-docx*.zip" | Sort-Object LastWriteTime -Descending | Select-Object -First 1
   Expand-Archive -LiteralPath $zip.FullName -DestinationPath . -Force
   Remove-Item -Recurse -Force .next -ErrorAction SilentlyContinue
   npm install
   npx supabase db push
   npm run typecheck
   npx vitest run --testTimeout=15000
   npm run dev

Expected use
------------
1. Sign in with a department account. The header shows its assigned primary
   department without a switch control.
2. Open Teaching allocation. Select any active trainer from the institution
   pool; the option shows the home department and total institutional load.
3. Open Timetable reports and select Trainer timetables.
4. Select "Export editable Word" to download
   personal-trainer-timetables-<period-code>.docx.
5. Each assigned trainer appears on a separate editable page containing all
   sessions allocated by any department.

Important operating rule
------------------------
Departments may allocate trainers from the shared institution pool, but an
automatic exchange still swaps only equal-duration units inside the same
department. Cross-department timetable occupancy is reserved globally so one
trainer cannot be placed in two departments at the same time.
